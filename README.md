# Tsukimi

Tsukimi is a high-performance, feature-rich manga reader for Android, designed with a focus on speed, customization, and a premium user experience.

## 🚀 Key Features

Tsukimi offers a comprehensive set of features to enhance your reading journey:

### 📥 Advanced Chapter Management
*   **Intuitive Controls:** Standard trash bin icon for easy identification of downloaded content.
*   **Safe Deletion:** Double-click protection on deletion to prevent accidental data loss.
*   **Instant UI Feedback:** Zero-latency interface updates during download and deletion operations.
*   **Visual Progress:** Circular progress indicators directly on download buttons.
*   **Smooth Experience:** Minimized background notifications for an uninterrupted reading flow.

### 👆 Intelligent Navigation
*   **Mass Selection:** Powerful range selection (long-press start and end) for bulk actions.
*   **Progress Tracking:** Batch "Mark as Read" and "Mark as Read Up to Here" capabilities.
*   **Quick Preview:** Long-press any manga to open a detailed BottomSheet preview with tags and metadata.
*   **Clean Interface:** Optimized menus focusing on essential tools.

### 📖 Enhanced Reader
*   **Precision Seeking:** Double-tap gesture for instant ±10 page jumps.
*   **Direct Reload:** Dedicated refresh button within the reader for quick content updates.
*   **Position Persistence:** Reliable auto-resume that remembers your exact page and scroll position.

### ✨ Performance & Design
*   **Tactile Response:** Haptic feedback for meaningful interactions throughout the app.
*   **Optimized Downloads:** Granular control over parallel source (up to 10) and page (up to 15) downloads.
*   **Anti-Bot Protection:** Advanced Cloudflare bypass with synchronized User-Agents and randomized interaction logic.
*   **Fluid Animations:** Graceful "fall down" animations for list loading and smooth transitions.
*   **Hassle-Free Updates:** Built-in automatic versioning and update system.

## 🎨 Branding
*   **Modern Visuals:** Featuring a unique application launcher icon and Material Design principles.
